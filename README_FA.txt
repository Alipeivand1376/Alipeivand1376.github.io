نسخه‌ی جدید وب‌سایت (دوزبانه + حالت تیره/روشن)

- index.html:
  عکس شخصی، همه‌ی تصاویر پژوهشی، اسلایدهای کنفرانس، دو ویدیوی پروژه‌ها و هر دو فایل رزومه (فعلی و اروپایی)
  همگی درون همین یک فایل قرار گرفته‌اند. برای نمایش سایت، همین یک فایل کافی است.

- preview.png:
  همان فایل قبلی؛ فقط برای پیش‌نمایش لینک در LinkedIn. کنار index.html بماند.

روش انتشار:
در ریپوی GitHub، فایل index.html قبلی را با این فایل جایگزین کن (Add file → Upload files → Commit).
۱ تا ۲ دقیقه بعد سایت به‌روز می‌شود. اگر تغییری ندیدی، صفحه را با Ctrl+Shift+R رفرش کن.

تنظیمات (پایین فایل، بخش <script>، فقط همین خط‌ها را عوض کن):
  WEB3FORMS_KEY     ← کلید Web3Forms تا فرم تماس کار کند (الان جای‌نگهدار است)
  CONTACT.whatsapp  ← شماره‌ی واتس‌اپ با فرمت 98 + شماره بدون صفر (مثلاً 989360917822)
  CONTACT.telegram  ← نام کاربری تلگرام بدون @ (اگر خالی باشد، لینک با شماره تلفن ساخته می‌شود)
  CONTACT.orcid     ← لینک کامل ORCID (اگر خالی باشد، آن ردیف نمایش داده نمی‌شود)
  CONTACT.linkedin  ← لینک دقیق پروفایل لینکدین را چک کن
  CONTACT.scholar   ← لینک Google Scholar (تنظیم شده)
  GOATCOUNTER_CODE  ← کد آمار بازدید (روی "alipeivand" تنظیم شده؛ آمار در https://alipeivand.goatcounter.com)

حالت پیش‌فرض رنگ: در بالای فایل، خط DEFAULT_THEME = "dark"
  "light" = روشن، "auto" = مطابق تنظیمات سیستم بازدیدکننده.

لینک مستقیم نسخه‌ی فارسی: آدرس سایت + ?lang=fa
  مثال: https://USERNAME.github.io/REPO/?lang=fa

ویرایش متن فارسی: هر جمله‌ی فارسی در ویژگی data-fa="..." دقیقاً کنار متن انگلیسی همان جمله است.
